## معماری کلی

```
┌─────────────────────────────┐
│      index.html             │  رابط کاربری کامل (تک‌فایل، بدون بیلد)
│  HTML + CSS + Vanilla JS    │  Chart.js · SheetJS · supabase-js
└──────────────┬──────────────┘
               │ HTTPS
┌──────────────▼──────────────┐
│         Supabase            │
│  ├── PostgreSQL (۴۸ جدول)   │  داده‌ها + RLS سطرمحور
│  ├── Auth                   │  ورود با نام کاربری/رمز
│  ├── Storage                │  بک‌آپ‌های شبانه
│  ├── Edge Functions (۵ تابع)│  ربات، اعلان، بک‌آپ، مدیریت کاربران
│  └── pg_cron + pg_net       │  زمان‌بندی خودکار
└──────────────┬──────────────┘
               │
┌──────────────▼──────────────┐
│   ربات تلگرام «سبزینه»      │  گزارش‌گیری با هوش مصنوعی
└─────────────────────────────┘
```

**نکته‌ی مهم:** رابط کاربری یک فایل HTML مستقل است — نیازی به Node.js، بیلد یا سرور اپلیکیشن ندارد. کافی است روی هر هاست استاتیکی آپلود شود.

## قابلیت‌های کلیدی

**داشبورد تحلیلی (۶ تب)**
نمای کلی · تولید · انبار · مالی · منابع انسانی · کیفیت

- **۱۷ اسلایسر چند‌انتخابی** با جستجو و شمارش رکورد
- **کراس‌فیلترینگ** — کلیک روی نمودار، کل داشبورد را فیلتر می‌کند
- نمودار **پارتو** (۸۰/۲۰)، **نقشه حرارتی**، نرخ‌ها، مقایسه با دوره قبل
- دریل‌ترو زمانی (سال ← ماه ← روز) و بزرگ‌نمایی هر نمودار

**فرم‌ساز**
۱۶ نوع فیلد · منطق شرطی · فیلد محاسباتی · انتخاب از دیتابیس · ثبت گروهی · پیش‌نمایش زنده · تکثیر فرم

**گردش کار**
مسیر تأیید قابل ویرایش برای هر فرم · سمت‌های سازمانی دلخواه · کارتابل · ارجاع خودکار به مدیرعامل

**امضای دیجیتال**
ثبت تصویر امضا برای هر کاربر · امضای اسناد · نمایش در برگه‌ی چاپی

**سایر**
ورود اکسل برای همه‌ی فرم‌ها · تم روشن/تیره · تقویم شمسی · جست‌وجوی سراسری · Command Palette (Ctrl+K) · قفل خودکار پس از بی‌کاری

## راه‌اندازی سریع

### پیش‌نیاز
یک پروژه‌ی Supabase (پلن رایگان کافی است) و یک هاست استاتیک.

### گام‌ها
۱. جدول‌ها و توابع دیتابیس را طبق [`docs/DATABASE.md`](docs/DATABASE.md) بسازید.
۲. توابع پوشه‌ی `supabase/functions/` را دیپلوی کنید.
۳. در `index.html` آدرس و کلید عمومی پروژه‌ی خود را جایگزین کنید:
   ```js
   const SUPABASE_URL = 'https://<project-ref>.supabase.co';
   const SUPABASE_ANON_KEY = '<anon-key>';
   ```
۴. `index.html` را روی هاست آپلود کنید ← [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)

> **کلید `anon` عمومی است و مشکل امنیتی ندارد** — تمام کنترل دسترسی در دیتابیس با RLS انجام می‌شود. کلید `service_role` هرگز نباید در این فایل قرار گیرد.

## امنیت

- کنترل دسترسی سطرمحور (RLS) روی تمام جدول‌ها
- سطح دسترسی به تفکیک ماژول و صفحه (`view` / `edit` / `none`)
- عملیات حساس فقط از طریق توابع `SECURITY DEFINER` با بررسی نقش
- توکن ربات و کلیدهای هوش مصنوعی فقط در جدول `bot_config` (بدون policy — تنها `service_role` می‌خواند)
- بک‌آپ خودکار شبانه با نگهداری ۳۰ روزه
- خروج خودکار پس از بی‌کاری
