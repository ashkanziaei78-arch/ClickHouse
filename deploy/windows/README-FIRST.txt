===============================================================
  سامانه ERP - شرکت تعاونی تولیدی پیشگامان صنعت سبز
  پکیج نصب روی ویندوز سرور
===============================================================

از کجا شروع کنم؟
---------------------------------------------------------------

فایل INSTALL-WINDOWS.md را باز کنید. کامل و مرحله‌به‌مرحله
نوشته شده است.

(اگر با Notepad باز کردید و به‌هم‌ریخته بود، با مرورگر
 یا Notepad++ یا VS Code باز کنید.)


خلاصه‌ی خیلی سریع
---------------------------------------------------------------

دو مسیر دارید:

  مسیر ۱ (ساده - پیشنهادی):
     سایت روی ویندوز سرور خودتان + دیتابیس روی Supabase ابری
     زمان: حدود ۳۰ دقیقه

  مسیر ۲ (همه‌چیز روی سرور خودتان):
     سایت + دیتابیس + ورود کاربران، همه روی ویندوز سرور
     زمان: نصف روز تا یک روز
     راهنما: پوشه docker\README.md


سه نکته که اگر رعایت نکنید سایت کار نمی‌کند
---------------------------------------------------------------

  ۱) پوشه vendor را حتما کنار index.html بگذارید.
     بدون آن، اگر سرور به اینترنت دسترسی نداشته باشد
     صفحه سفید می‌ماند.

  ۲) فایل web.config را هم در همان پوشه بگذارید.
     بدون آن فونت فارسی درست نمایش داده نمی‌شود.

  ۳) برای ورود کاربران، فقط PostgreSQL کافی نیست.
     Supabase لازم است (ابری یا روی سرور خودتان).
     توضیح کامل در INSTALL-WINDOWS.md


محتویات پکیج
---------------------------------------------------------------

  app\                  کل سامانه (index.html + vendor)
  database\             فایل‌های SQL نصب دیتابیس
  iis\                  تنظیمات IIS ویندوز
  docker\               نصب Supabase روی سرور خودتان
  edge-functions\       توابع سمت سرور (ربات تلگرام، پشتیبان‌گیری)
  scripts\              فایل‌های bat برای نصب خودکار
  INSTALL-WINDOWS.md    راهنمای کامل نصب
