===================================================================
   بخش ۱ - این پکیج چیست
===================================================================

این یک سامانه کامل ERP است که روی هاست خودتان نصب می شود.
هیچ داده ای به هیچ سرویس بیرونی فرستاده نمی شود. همه چیز روی
سرور خودتان می ماند.

محتویات پکیج:

   index.html                   صفحه اصلی سامانه (خود برنامه)
   erp-api.js                   ارتباط برنامه با سرور
   vendor/                      فونت فارسی و کتابخانه نمودار و اکسل
   api/                         برنامه های سمت سرور (PHP)
   bot/telegram.php             ربات تلگرام «سبزینه»
   database/mysql_schema.sql    ساختار دیتابیس برای MySQL
   database/pgsql_schema.sql    ساختار دیتابیس برای PostgreSQL
   install.php                  نصاب خودکار
   uploads/                     محل ذخیره فایل های آپلود شده

نکته مهم: دیتابیس کاملا خالی است. هیچ داده آزمایشی داخلش نیست.
شما فقط یک حساب مدیر می سازید و بقیه اطلاعات را خودتان وارد می کنید.


===================================================================
   بخش ۲ - چه هاستی بخرم
===================================================================

حداقل چیزی که هاست باید داشته باشد:

   - PHP نسخه ۸.۰ یا بالاتر  (ترجیحا ۸.۲ یا ۸.۳)
   - یکی از این دو:  MySQL 5.7+ / MariaDB 10.3+   یا   PostgreSQL 12+
   - افزونه های PHP:  pdo_mysql یا pdo_pgsql ، mbstring ، json ، curl
   - گواهی SSL رایگان (Let's Encrypt) - تقریبا همه هاست ها دارند
   - حداقل ۱ گیگابایت فضا

توصیه:

   اگر می خواهید ساده ترین راه را بروید:
      یک «هاست لینوکس اشتراکی» با cPanel یا DirectAdmin بخرید.
      این ها همیشه MySQL دارند. قیمتشان هم کم است.

   اگر می خواهید PostgreSQL داشته باشید:
      اکثر هاست های اشتراکی PostgreSQL ندارند.
      برای PostgreSQL باید «سرور مجازی» (VPS) بگیرید،
      یا هاستی که صریحا نوشته PostgreSQL دارد.

   کدام بهتر است؟
      برای این سامانه هر دو کاملا خوب کار می کنند.
      MySQL راحت تر پیدا می شود. PostgreSQL برای گزارش های
      سنگین تر و Power BI کمی قوی تر است.
      اگر شک دارید: MySQL بگیرید.

نکته مهم درباره دامنه:
   دامنه ir. از ایرنیک می گیرید. دامنه com. از هر ثبت کننده ای.
   حتما بعد از نصب، سایت را روی https بیندازید نه http.


===================================================================
   بخش ۳ - ساخت دیتابیس
===================================================================

--------------------------------------------------------
   الف) اگر MySQL / MariaDB دارید  (حالت معمول)
--------------------------------------------------------

   ۱. وارد cPanel شوید
   ۲. دنبال آیکون «MySQL Databases» بگردید و رویش کلیک کنید
   ۳. در کادر «Create New Database» یک اسم بنویسید، مثلا:  erp
      (cPanel خودش جلویش نام اکانت شما را می گذارد،
       مثلا می شود:  myuser_erp  - این نام کامل را یادداشت کنید)
   ۴. پایین تر در «MySQL Users» یک کاربر بسازید
      مثلا نام:  erpuser   و یک رمز قوی
      (باز هم کامل می شود:  myuser_erpuser  - یادداشت کنید)
   ۵. باز هم پایین تر در «Add User To Database»
      کاربر و دیتابیس را انتخاب کنید و Add را بزنید
   ۶. در صفحه بعد تیک «ALL PRIVILEGES» را بزنید و Make Changes

   در پایان این ۴ چیز را باید داشته باشید:
      نام دیتابیس    مثلا  myuser_erp
      نام کاربر      مثلا  myuser_erpuser
      رمز کاربر      همانی که خودتان گذاشتید
      آدرس سرور      معمولا  localhost


--------------------------------------------------------
   ب) اگر PostgreSQL دارید
--------------------------------------------------------

   حالت ۱ - هاست شما در cPanel گزینه PostgreSQL دارد:

      ۱. وارد cPanel شوید
      ۲. روی «PostgreSQL Databases» کلیک کنید
      ۳. دقیقا مثل بالا: دیتابیس بسازید، کاربر بسازید،
         کاربر را به دیتابیس اضافه کنید با همه دسترسی ها
      ۴. آدرس سرور  localhost  و پورت  5432

   حالت ۲ - سرور مجازی (VPS) اوبونتو دارید:

      این دستورها را در SSH بزنید:

         sudo apt update
         sudo apt install postgresql postgresql-contrib
         sudo -u postgres psql

      حالا داخل postgres این ها را بزنید (رمز را عوض کنید):

         CREATE USER erpuser WITH PASSWORD 'یک_رمز_خیلی_قوی';
         CREATE DATABASE erpdb OWNER erpuser;
         GRANT ALL PRIVILEGES ON DATABASE erpdb TO erpuser;
         \q

      در پایان:
         نام دیتابیس   erpdb
         نام کاربر     erpuser
         رمز           همانی که گذاشتید
         آدرس سرور     localhost
         پورت          5432

   خیلی مهم:
      هرگز پورت دیتابیس (3306 یا 5432) را روی اینترنت باز نکنید.
      دیتابیس فقط باید از روی خود سرور قابل دسترس باشد.
      اگر لازم شد از بیرون وصل شوید، از SSH Tunnel استفاده کنید
      (در بخش ۹ توضیح داده شده).


===================================================================
   بخش ۴ - آپلود فایل ها روی هاست
===================================================================

   ۱. فایل زیپ را روی کامپیوتر خودتان از حالت فشرده خارج کنید
   ۲. وارد cPanel شوید و «File Manager» را باز کنید
   ۳. وارد پوشه  public_html  شوید
   ۴. اگر فایل های قدیمی داخلش هست (مثل index.html پیش فرض هاست)
      آن ها را پاک کنید
   ۵. دکمه Upload را بزنید و کل فایل زیپ را آپلود کنید
   ۶. بعد از آپلود، روی فایل زیپ راست کلیک کنید و Extract بزنید

   بعد از اکسترکت باید این ها را داخل public_html ببینید:

      index.html
      erp-api.js
      install.php
      api/
      bot/
      database/
      uploads/
      vendor/

   دقت کنید: اگر همه این ها داخل یک پوشه دیگر رفتند
   (مثلا public_html/sanat-sabz-erp-host/) آن ها را بکشید
   و مستقیم داخل public_html بگذارید.

   تنظیم دسترسی پوشه ها (در File Manager راست کلیک > Permissions):
      پوشه  uploads     ->  755
      پوشه  api         ->  755
      بقیه فایل ها      ->  644


===================================================================
   بخش ۵ - اجرای نصاب
===================================================================

   در مرورگر این آدرس را باز کنید (به جای yourdomain.ir دامنه خودتان):

      https://yourdomain.ir/install.php

   یک صفحه فارسی باز می شود. مراحل:

   ۱) بررسی پیش نیازها
      همه موارد باید سبز و «درست» باشند.
      اگر PHP قرمز بود: در cPanel بخش «Select PHP Version»
      نسخه را روی ۸.۲ بگذارید.
      اگر افزونه ای قرمز بود: در همان صفحه تیک آن افزونه را بزنید.

   ۲) نوع دیتابیس
      MySQL یا PostgreSQL را انتخاب کنید.
      نصاب خودش می فهمد کدامشان روی هاست شما موجود است
      و گزینه ای که موجود نیست را غیرفعال نشان می دهد.

   ۳) اطلاعات دیتابیس
      همان ۴ چیزی که در بخش ۳ یادداشت کردید را اینجا وارد کنید.

   ۴) کاربر مدیر سامانه
      نام کاربری: با حروف انگلیسی، مثلا  admin
      رمز عبور  : حداقل ۸ کاراکتر - یک رمز قوی بگذارید
      نام نمایشی: مثلا  مدیر سیستم

   ۵) دکمه «شروع نصب» را بزنید

   اگر همه چیز درست باشد، پیام سبز «نصب با موفقیت انجام شد»
   را می بینید و می توانید وارد سامانه شوید.


===================================================================
   بخش ۶ - کارهای امنیتی بعد از نصب (خیلی مهم)
===================================================================

   این کارها را همان روز اول انجام دهید:

   ۱) فایل install.php را پاک کنید
      این از همه مهم تر است. تا وقتی این فایل روی سرور باشد،
      هر کسی می تواند دوباره نصب را اجرا کند.
      File Manager > روی install.php راست کلیک > Delete

   ۲) پوشه database را پاک کنید
      بعد از نصب دیگر لازم نیست.
      (اگر نگهش داشتید حداقل مطمئن شوید که کسی نمی تواند
       فایل sql. را دانلود کند.)

   ۳) SSL را اجباری کنید
      در cPanel بخش «Domains» گزینه «Force HTTPS Redirect»
      را روشن کنید. یا این خطوط را به فایل htaccess. در
      public_html اضافه کنید:

         RewriteEngine On
         RewriteCond %{HTTPS} off
         RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

   ۴) رمز مدیر را قوی نگه دارید
      حداقل ۱۲ کاراکتر، ترکیب حروف بزرگ و کوچک و عدد و علامت.

   ۵) فایل api/config.php را جابه جا یا حفاظت نکنید - خودش امن است
      این فایل رمز دیتابیس را دارد ولی چون php. است، محتوایش
      هرگز به مرورگر فرستاده نمی شود. پوشه api یک فایل htaccess.
      دارد که دسترسی مستقیم را هم می بندد.

   چیزهایی که سامانه خودش انجام می دهد:
      - رمزها با bcrypt هش می شوند (رمز خام هیچ جا ذخیره نمی شود)
      - بعد از ۵ تلاش ناموفق، حساب ۱۵ دقیقه قفل می شود
      - هر درخواست قبل از رسیدن به دیتابیس از فیلتر دسترسی رد می شود
      - آپلود فایل php در پوشه uploads مسدود است
      - نشست کاربر بعد از ۱۲ ساعت منقضی می شود


===================================================================
   بخش ۷ - ساخت کاربران و سطح دسترسی
===================================================================

   ۱. با حساب مدیری که ساختید وارد سامانه شوید
   ۲. از منو بروید به بخش «مدیریت کاربران»
   ۳. دکمه «کاربر جدید» را بزنید
   ۴. برای هر نفر مشخص کنید:
         نام و نام خانوادگی
         نام کاربری (انگلیسی)
         رمز اولیه
         سمت سازمانی (مدیرعامل، مدیرتولید، انباردار و ...)
         دسترسی هر بخش: بدون دسترسی / فقط خواندن / خواندن و نوشتن

   سمت سازمانی مهم است چون گردش کار تاییدها بر اساس آن است.
   مثلا گزارش تولید اول باید «برنامه ریزی تولید» تایید کند
   و بعد «مدیرعامل».

   برای تغییر مسیر تاییدها: بخش «تنظیمات گردش کار»


===================================================================
   بخش ۸ - ربات تلگرام «سبزینه»
===================================================================

   ربات داخل همین پکیج است: فایل  bot/telegram.php

   با این ربات، مدیران می توانند از داخل تلگرام گزارش بگیرند
   بدون اینکه سایت را باز کنند.

   راه اندازی کامل در فایل جداگانه توضیح داده شده:

         راهنمای-ربات-تلگرام.txt

   خلاصه اش:
      ۱. در تلگرام از BotFather@ یک ربات بسازید و توکن بگیرید
      ۲. یک «رمز وب هوک» بسازید (یک رشته تصادفی طولانی)
      ۳. در سامانه بخش «تنظیمات ربات» هر دو را وارد کنید
      ۴. یک آدرس به تلگرام بدهید تا پیام ها را به ربات شما بفرستد

   نکته امنیتی: ربات فقط می خواند و هیچ چیزی را تغییر نمی دهد.
   هر کاربر باید با همان نام کاربری و رمز سامانه وارد ربات شود
   و دقیقا همان سطح دسترسی سامانه را در ربات دارد.


===================================================================
   بخش ۹ - اتصال به Power BI
===================================================================

   دیتابیس شما یک دیتابیس SQL استاندارد است، پس Power BI
   مستقیم به آن وصل می شود.

   راه امن (پیشنهادی) - از طریق تونل SSH:

      ۱. یک برنامه SSH مثل PuTTY نصب کنید
      ۲. در PuTTY بخش Connection > SSH > Tunnels:
            Source port:  5432   (برای MySQL بنویسید 3306)
            Destination:  localhost:5432   (یا localhost:3306)
            Local را انتخاب کنید و Add بزنید
      ۳. با SSH به سرور وصل شوید و پنجره را باز نگه دارید
      ۴. در Power BI:
            Get Data > PostgreSQL database  (یا MySQL database)
            Server:    localhost:5432
            Database:  نام دیتابیس شما
            Username / Password: همان کاربر دیتابیس

   چرا تونل؟ چون این طوری لازم نیست پورت دیتابیس را روی
   اینترنت باز کنید. اگر باز کنید، هر کسی در دنیا می تواند
   رمز را حدس بزند.

   پیشنهاد: برای Power BI یک کاربر دیتابیس جداگانه بسازید
   که فقط اجازه خواندن (SELECT) داشته باشد.

      در PostgreSQL:
         CREATE USER bi_reader WITH PASSWORD 'رمز_قوی';
         GRANT CONNECT ON DATABASE erpdb TO bi_reader;
         GRANT USAGE ON SCHEMA public TO bi_reader;
         GRANT SELECT ON ALL TABLES IN SCHEMA public TO bi_reader;

      در MySQL:
         CREATE USER 'bi_reader'@'localhost' IDENTIFIED BY 'رمز_قوی';
         GRANT SELECT ON نام_دیتابیس.* TO 'bi_reader'@'localhost';
         FLUSH PRIVILEGES;

   جدول های مهم برای گزارش گیری:
      daily_reports         گزارش روزانه تولید
      sheeter_reports       گزارش شیتر
      packaging_reports     گزارش بسته بندی
      stop_reports          توقفات خط
      inventory_items       موجودی انبار
      inventory_moves       ورود و خروج انبار
      sales_orders          سفارش های فروش
      treasury_entries      خزانه
      hr_employees          پرسنل


===================================================================
   بخش ۱۰ - پشتیبان گیری
===================================================================

   این کار را جدی بگیرید. حداقل هفته ای یک بار.

   الف) از داخل cPanel (ساده ترین راه):
      cPanel > Backup > Download a MySQL Database Backup
      روی نام دیتابیس کلیک کنید تا فایل sql. دانلود شود.

   ب) با دستور (اگر SSH دارید):

      MySQL:
         mysqldump -u کاربر -p نام_دیتابیس > backup.sql

      PostgreSQL:
         pg_dump -U کاربر -d نام_دیتابیس > backup.sql

   ج) پوشه uploads را هم جدا بگیرید
      (فایل های پیوست و امضاها آنجا هستند)

   برگرداندن پشتیبان:

      MySQL:
         mysql -u کاربر -p نام_دیتابیس < backup.sql

      PostgreSQL:
         psql -U کاربر -d نام_دیتابیس -f backup.sql


===================================================================
   بخش ۱۱ - مشکلات رایج و راه حل
===================================================================

   صفحه سفید باز می شود / هیچ چیز نشان نمی دهد
   -----------------------------------------------------------
      معمولا یعنی فایل های پوشه vendor آپلود نشده اند.
      چک کنید که پوشه vendor و فایل های داخلش کامل باشند.
      اگر مشکل ادامه داشت، در مرورگر کلید F12 را بزنید و
      بخش Console را ببینید.


   پیام «اتصال به دیتابیس ناموفق بود»
   -----------------------------------------------------------
      یکی از این هاست:
      - نام دیتابیس اشتباه است (یادتان باشد cPanel جلوی اسم،
        نام اکانت را می گذارد: myuser_erp نه فقط erp)
      - نام کاربر اشتباه است (باز هم myuser_erpuser)
      - رمز اشتباه است
      - کاربر را به دیتابیس اضافه نکرده اید (بخش ۳ قدم ۵ و ۶)
      - آدرس سرور را عوض کنید: به جای localhost بنویسید 127.0.0.1


   پیام «افزونه pdo_pgsql فعال نیست»
   -----------------------------------------------------------
      هاست شما PostgreSQL ندارد.
      یا MySQL را انتخاب کنید، یا از پشتیبانی هاست بخواهید
      افزونه را فعال کند، یا هاست را عوض کنید.


   خطای 500 روی صفحه
   -----------------------------------------------------------
      نسخه PHP پایین است. در cPanel بخش «Select PHP Version»
      نسخه را روی ۸.۲ بگذارید.
      اگر باز هم بود: cPanel > Errors  را ببینید،
      یا از پشتیبانی هاست بخواهید error log را برایتان بفرستند.


   وارد می شوم ولی می گوید «نام کاربری یا رمز اشتباه است»
   -----------------------------------------------------------
      - حروف بزرگ و کوچک مهم است
      - اگر ۵ بار اشتباه زده اید، ۱۵ دقیقه صبر کنید (قفل موقت)
      - اگر رمز مدیر را فراموش کردید: بخش «بازیابی رمز مدیر»
        پایین همین فایل


   فایل آپلود نمی شود
   -----------------------------------------------------------
      دسترسی پوشه uploads را روی 755 بگذارید.
      حداکثر حجم فایل ۲ مگابایت است. برای تغییر، در فایل
      api/config.php خط MAX_UPLOAD_BYTES را عوض کنید.


   داده ها دیر به روز می شوند
   -----------------------------------------------------------
      سامانه هر ۲۰ ثانیه یک بار تغییرات را چک می کند.
      این طبیعی است. اگر فوری می خواهید، صفحه را رفرش کنید.


   بازیابی رمز مدیر (اگر رمز را فراموش کردید)
   -----------------------------------------------------------
      یک فایل به نام  reset.php  در public_html بسازید با این محتوا
      (به جای admin و NEWPASS مقادیر خودتان را بگذارید):

         <?php
         require __DIR__ . '/api/lib.php';
         $h = password_hash('NEWPASS', PASSWORD_BCRYPT);
         $s = db()->prepare('UPDATE app_users SET password_hash = ?,
                             failed_tries = 0, locked_until = NULL
                             WHERE username = ?');
         $s->execute([$h, 'admin']);
         echo 'رمز عوض شد';

      یک بار در مرورگر بازش کنید، بعد حتما فورا پاکش کنید.
